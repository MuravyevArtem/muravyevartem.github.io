◇ Коротко о главном Четыре типа данных и одна важная команда

Python выполняет команды по порядку. print() выводит значение, а type() помогает определить его тип. Переменная — это имя, связанное со значением. Команда score = 10 присваивает имени score значение 10. Новое присваивание меняет значение переменной.

intЦелое число12, -3
floatЧисло с дробной частью3.5
strТекст в кавычках"Привет", "12"
boolЛогическое значениеTrue, False

Нужна подсказка?

Кавычки превращают запись в строку. False — логическое значение, а "False" — текст.

Отметь все допустимые имена и исправь одно недопустимое.

Имя не начинается с цифры и не содержит пробелов. Можно использовать буквы, цифры и _. Регистр важен: score и Score — разные имена. Ключевые слова Python использовать нельзя.
